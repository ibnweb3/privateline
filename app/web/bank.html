On Canton MainNet (our next milestone)

  1. A Nigerian payment provider (for example Paystack, Flutterwave or Monnify) gives each user a real deposit account number, and notifies PrivateLine when naira lands. This demo uses the same notification format, signed the same way.
  2. A licensed exchange (Busha and Quidax hold SEC Nigeria approval) converts naira to USDC. PrivateLine never swaps naira itself.
  3. Circle xReserve mints the USDC as USDCx on Canton, into the vault. A float of USDCx lets deposits be credited instantly and refilled in daily batches.
  4. Withdrawals run in reverse, and only to the user's own funding account.
